Customer & Product Management System - 
A simple Customer & Product Management System built with PHP & MySQL.
This project demonstrates CRUD operations, Transaction Management, and Bill Generation with a user-friendly interface.
________________________________________
🚀 Features
•	👤 Customer Management
->	Insert, Update, Delete, View Customers |
•	📦 Product Management
->	Insert, Update, Delete, View Products |
•	🔎 Display Options
->	View all records
->	Search specific customer and their purchased products |
•	💳 Transaction & Billing
->	Record transactions (Customer ↔ Product)
->	Generate Bill with Quantity × Price calculation |
•	📂 Dropdown Navigation (from mainc.php)
________________________________________
🛠 Tech Stack
•	Frontend: HTML, CSS (custom cp.css)
•	Backend: PHP (Procedural)
•	Database: MySQL
